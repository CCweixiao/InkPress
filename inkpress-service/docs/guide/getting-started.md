# InkPress Service 快速上手

InkPress Service 是 InkPress 的用户服务与授权中心，负责账号注册、订阅购买、License 发放、设备激活、订单管理和售后工单。它和桌面端配合使用：网站完成账号与授权，桌面端专注写作、排版和发布。

## 典型使用路径

| 步骤 | 入口 | 你会完成什么 |
| --- | --- | --- |
| 1 | 首页 | 了解 InkPress 的写作、排版、素材与发布能力 |
| 2 | 注册 / 登录 | 创建账号，进入个人控制台 |
| 3 | 价格方案 | 选择适合的授权计划并完成支付 |
| 4 | 控制台 | 查看订单与 License Key |
| 5 | 桌面端 | 粘贴 License Key 并完成设备激活 |

## 首页导航说明

- **功能**：了解 InkPress 能解决的核心场景，包括公众号写作、Markdown 排版、素材管理和 AI 辅助。
- **流程**：查看从创作到发布的工作链路。
- **价格**：选择订阅计划，已登录用户会直接进入支付流程。
- **使用指引**：打开当前本地手册，左侧是目录，右侧渲染 Markdown 文档。
- **控制台**：登录后查看 License、订单、工单和个人设置。
- **管理后台**：管理员账号专属入口。

## 首次购买建议

1. 先登录或注册账号，避免支付后订单无法归属。
2. 在价格区选择方案，确认设备数和有效期。
3. 支付成功后进入控制台查看 License。
4. 在桌面端激活，如果设备数已满，先在控制台核对历史设备。

> 如果你是团队或企业用户，建议先通过工单说明设备数量、交付周期和发票要求，管理员可以在后台生成更合适的授权方案。
