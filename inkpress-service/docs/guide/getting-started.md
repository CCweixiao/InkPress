# InkPress 快速上手

InkPress 是面向公众号创作者、技术作者和内容团队的写作排版工具。它把 AI 辅助创作、Markdown 写作、素材整理、文章预览和发布前检查放在一条清晰的工作流里，让你把时间更多留给内容本身。

## 典型使用路径

| 步骤 | 入口 | 你会完成什么 |
| --- | --- | --- |
| 1 | 首页 | 了解 InkPress 的写作、排版、素材与发布能力 |
| 2 | 使用指引 | 查看产品上手、创作工作流和用户中心说明 |
| 3 | 注册 / 登录 | 创建账号，进入用户中心 |
| 4 | 创作工作区 | 开始写作、整理素材、调整排版 |
| 5 | 预览与发布 | 检查图文效果，再交付到发布渠道 |

## 首页导航说明

- **功能**：了解 InkPress 能解决的核心场景，包括公众号写作、Markdown 排版、素材管理和 AI 辅助。
- **流程**：查看从创作到发布的工作链路。
- **价格**：了解不同使用方案，选择适合自己的版本。
- **使用指引**：打开当前本地手册，左侧是目录，右侧渲染 Markdown 文档。
- **控制台**：登录后查看订单、个人资料、账号安全和问题反馈。

## 第一次使用建议

1. 先看一遍「创作工作流」，理解文章从草稿到成稿会经过哪些步骤。
2. 准备一篇已有文章或一个选题，用 InkPress 完成一次完整排版。
3. 把常用封面、配图和附件放进素材区，后续文章可以复用。
4. 发布前使用预览检查标题、摘要、图片比例、代码块和表格。

> 如果你是团队用户，可以先约定统一的标题、封面、摘要和排版规范，再把这些规范沉淀到团队协作流程里。
