# 创作工作流

InkPress 的核心目标是把「写作」和「交付」之间的杂事变少。你可以把它理解成一个面向公众号与长文内容的工作台：先写清楚，再排漂亮，最后检查发布效果。

## 一篇文章的推荐流程

| 阶段 | 你要关注什么 | InkPress 能帮你做什么 |
| --- | --- | --- |
| 选题 | 主题、受众、角度 | 梳理提纲、标题方向和内容结构 |
| 写作 | 正文、代码块、表格、引用 | 使用 Markdown 保持结构清晰 |
| 排版 | 标题层级、段落节奏、重点强调 | 统一样式，减少手动格式调整 |
| 素材 | 封面、配图、附件 | 统一管理文章相关素材 |
| 预览 | 手机端阅读体验 | 检查图文比例、摘要和整体观感 |
| 发布 | 草稿交付和最终检查 | 减少复制粘贴带来的格式损耗 |

## 写作建议

- 标题先写清楚受众和收益，不要只写抽象概念。
- 正文先搭结构，再补细节，避免一开始陷入局部措辞。
- 代码块、表格和列表尽量保持 Markdown 原始结构，便于后续维护。
- 图片不要只当装饰，尽量服务于解释、对比或步骤说明。

## 发布前检查

1. 标题是否清楚表达文章主题。
2. 摘要是否能说明读者为什么要点开。
3. 封面图是否与主题一致，移动端裁切后是否仍然可读。
4. 正文是否存在过长段落、断裂层级或重复小标题。
5. 代码块、表格和引用在预览中是否完整。

```text
推荐节奏：
先完成内容结构，再调整视觉样式。
先检查移动端阅读，再处理细节润色。
```
