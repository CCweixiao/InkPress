# License 激活

License Key 是 InkPress 桌面端的授权凭证。每个 Key 都有设备上限、有效期策略和激活状态，控制台会展示与当前账号邮箱归属一致的 License。

## 激活前检查

- 确认你已经登录购买时使用的账号。
- 在 **控制台 → 我的 License** 找到对应授权。
- 点击查看 Key，复制完整 License Key。
- 确认桌面端网络可访问授权服务。

## 激活流程

1. 打开 InkPress 桌面端。
2. 进入 License 激活页。
3. 粘贴控制台中复制的 License Key。
4. 点击激活，等待设备绑定完成。
5. 回到控制台刷新，可以看到激活设备数量变化。

## 设备数与换机

| 场景 | 处理方式 |
| --- | --- |
| 新设备首次激活 | 直接使用 License Key 激活 |
| 设备数达到上限 | 先处理不再使用的旧设备，再激活新设备 |
| 系统重装 | 如果设备指纹变化，可能会占用新的设备名额 |
| 授权过期 | 购买新计划或联系管理员延长 License |

## 常见错误

- **Key 不存在**：检查是否复制完整，避免漏掉前后字符。
- **设备数已满**：在控制台查看已激活设备，必要时提交工单。
- **License 已停用**：可能存在退款、风控或管理员手动停用记录。
- **网络请求失败**：检查代理、企业网络拦截或服务器地址配置。
