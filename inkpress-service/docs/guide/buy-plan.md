# InkPress License 购买与激活指南

这篇文章带你走完 InkPress 的购买到激活全流程，总共四步：选套餐 → 支付 → 领 License Key → 在软件里激活。每一步都配了截图，跟着做就行。

---

## 第一步：选择 License 套餐

打开 InkPress 的定价页面：

👉 **https://www.longoflow.com/#pricing**

页面会列出所有可购买的 License 套餐，目前提供四个版本：

| 套餐版本 | 说明 |
|---------|------|
| 1 年版 | 有效期 1 年，到期后需续费 |
| 3 年版 | 有效期 3 年 |
| 5 年版 | 有效期 5 年 |
| 终身版 | 一次购买，永久使用 |

具体价格以页面上实时显示的为准。

![InkPress License 套餐页面，包含 1 年版、3 年版、5 年版和终身版四个选项](/guide-images/2026-07-10/77058b92-aeeb-4379-aa19-0861c6ae6e24.png)

**怎么做：** 选一个你需要的版本，点击对应的「购买」按钮，会自动跳转到 InkPress 收银台。

---

## 第二步：在收银台确认订单

点击购买后会跳转到 InkPress 收银台页面，这里会显示你选择的套餐和需要支付的金额。

![InkPress 收银台页面，确认套餐与金额后点击支付](/guide-images/2026-07-10/b3a6aa0c-9b3b-4ac7-b954-8b59556260e2.png)

**怎么做：** 核对套餐名称和金额没问题后，点击「支付」按钮，系统会弹出支付宝收款码。

---

## 第三步：扫码完成支付

支付方式是支付宝。点击支付后，页面会显示一个支付宝收款二维码。

![支付宝收款码页面，用支付宝扫码完成付款](/guide-images/2026-07-10/718d7342-75d8-4382-ad54-22c31e7987b1.png)

**怎么做：**

1. 打开手机支付宝，扫描页面上的二维码。
2. 确认金额后完成付款。
3. 支付成功后，页面会自动跳转回收银台，提示交易完成。

> 💡 付款金额一定要和收银台显示的一致，付错金额可能导致系统无法自动识别。

---

## 第四步：在订单详情领取 License Key

支付完成后，InkPress 会自动为你生成 License Key。你需要到后台订单里把它找出来。

**怎么做：**

1. 打开 InkPress 后台，进入「订单」页面。
2. 找到状态为「交易成功」的那条订单（就是你刚支付的那笔）。
3. 点开订单详情，就能看到自动分发的 License Key。

![订单详情页，支付成功后可查看自动分发的 License Key](/guide-images/2026-07-10/bd48bae1-b68a-4ebc-b25d-8d106c3b35de.png)

**建议：** 把这串 License Key 复制保存好（比如存到备忘录或密码管理器），后面激活和换设备都会用到。

---

## 第五步：在软件中激活

拿到 License Key 后，回到 InkPress 软件里完成最后一步激活。

**怎么做：**

1. 打开 InkPress 软件，进入「设置」页。
2. 找到「License」选项。
3. 把刚才复制的 License Key 粘贴进去。
4. 确认激活。

![在设置页 License 界面输入 License Key 完成激活](/guide-images/2026-07-10/b80c757a-de13-4711-a560-22139ea7445e.png)

激活成功后，软件就能正常使用全部功能了。

---

## 常见问题排查

**Q：付完款没看到 License Key，怎么办？**
先到后台「订单」页面确认订单状态是不是「交易成功」。如果状态还是待支付或处理中，可能是支付回调有延迟，等几分钟再刷新看看。如果一直没更新，带着订单号联系客服。

**Q：License Key 输入后提示无效？**
检查几个地方：
- 复制时有没有多带空格或漏掉字符，建议直接全选复制，不要手敲。
- 确认这串 Key 是当前这个订单分发的，别用错了。
- 大小写要和订单详情里显示的完全一致。

**Q：付完款页面没自动跳转？**
这通常是网络或浏览器的问题。不用慌，付款成功与否以支付宝扣款记录为准。直接去后台订单页查一下状态就知道结果。

**Q：换电脑或重装系统后还能用吗？**
License Key 是你的购买凭证，妥善保存后可在新设备上重新激活。如果遇到设备绑定限制无法激活，带上订单信息联系客服协助重置。

**Q：1 年版到期后会怎样？**
到期后 License 失效，需要重新购买续费才能继续使用。终身版不存在这个问题。

---

整个流程就是这些：选套餐 → 收银台确认 → 支付宝付款 → 订单里领 Key → 软件里激活。过程中遇到任何卡点，优先回订单页确认状态，再对照上面的排查清单逐项检查。
