# 快速上手：在 Windows 上安装 InkPress

很多人用 Mac 装 InkPress 一路顺畅，换到 Windows 却不知道从哪下手。

其实 Windows 版的安装流程和 Mac 基本一致，只是文件格式从 `.dmg` 变成了 `.exe`。今天就带你走一遍完整流程，三步搞定。

---

## 第一步：找到安装包，启动安装

下载完成后，打开浏览器的**下载目录**（一般在 `C:\Users\你的用户名\Downloads`），找到 InkPress 的 `.exe` 安装包。

双击运行，会弹出安装界面。这时候注意一个选项——**「为当前用户安装」**。

![找到 exe 安装包，选择为当前用户安装](/guide-images/2026-07-10/e86f409a-1338-4054-af31-fba108c6c5ee.png)

选「为当前用户安装」就够了，不需要选「为所有用户安装」。前者不需要管理员权限，装起来更顺利，也避免权限问题导致后续更新出毛病。

---

## 第二步：选择安装目录

接下来会让你选安装路径。

**默认装在 C 盘**，但如果你 C 盘空间紧张，或者习惯把软件放到别的盘，这一步可以手动改一下。

![选择安装目录，默认 C 盘，可切换其他盘符](/guide-images/2026-07-10/c21debd6-ea56-4713-8f74-93fef979f2dd.png)

操作很简单：点击路径栏旁边的\*\*「浏览」**或**「更改」\*\*按钮，选一个你习惯的盘符和文件夹就行。

> 💡 小建议：路径里尽量别有中文和空格，比如 `D:\Program Files\InkPress` 就比 `D:\我的软件\Ink Press` 省心得多。

---

## 第三步：等待安装完成

选好目录后，点击「安装」，就会进入进度条界面。

![安装进行中，耐心等待进度条走完](/guide-images/2026-07-10/25c4e123-d8f9-46b5-b5ec-f8ef0de8b2e3.png)

这一步可能会**比预期慢一些**，尤其是第一次安装，属于正常现象——软件在解压和写入文件，耐心等进度条走完就好。

安装完成后，桌面或开始菜单会出现 InkPress 的图标，点击即可启动。

---

## 安装小结

整个过程就三件事：

1. **双击 exe** → 选「为当前用户安装」
2. **选目录** → 不想占 C 盘就换个盘
3. **等进度条** → 慢一点别慌，走完就好

和 Mac 端的逻辑完全一样：下载 → 选位置 → 等安装。只是操作细节跟着 Windows 的习惯走。

装好之后打开 InkPress，做好配置之后，就可以开始用了。如果在安装过程中遇到任何报错，把截图发给我们，帮你排查。
