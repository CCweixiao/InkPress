# 管理后台

管理后台只对管理员开放，用于维护商业计划、订单、用户、License、工单和审计日志。普通用户会自动跳转回控制台。

## 后台模块

| 模块 | 用途 |
| --- | --- |
| License | 生成授权、查看状态、延长有效期、查看激活记录 |
| 订单 | 核对支付状态、订单号、套餐和用户归属 |
| 订阅计划 | 配置价格、折扣、设备数、权益和展示顺序 |
| 用户 | 管理账号状态、角色和基础资料 |
| 工单 | 回复用户问题、处理附件和售后状态 |
| 审计日志 | 追踪关键管理动作，方便排障和风控 |

## 管理建议

- 调整价格或折扣前，先确认首页价格区的展示顺序和高亮策略。
- 手动生成 License 时，尽量绑定用户邮箱和邀请码，方便用户在控制台自助查看。
- 处理工单时，优先记录结论，避免关键操作只留在即时通讯里。
- 审计日志不要随意清理，它是定位误操作和异常行为的重要线索。

## 导航设计

后台顶部保留两个层级：

1. 全局入口：主页、控制台、用户区、退出。
2. 后台模块：License、订单、订阅计划、用户、工单、审计日志。

这样管理员不会在“用户控制台”和“后台管理”之间迷路，也能快速回到公开首页查看用户侧展示。
