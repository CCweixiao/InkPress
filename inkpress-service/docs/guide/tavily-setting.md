# 让 InkPress Agent 联网：Tavily 免费 API Key 配置指引

InkPress 的写作 Agent 默认只能用你给的素材和它自己的训练知识写文章。一旦碰到「2026 年 7 月某产品最新价格」「某个库最新版本 API」这类问题，它就抓瞎——训练数据有截止日期。

配上联网搜索（基于 Tavily），Agent 在写作前能像真人一样去搜索引擎查最新资料、抓取网页正文，再把可回溯的来源写进文章里。免费账户每月 1,000 次额度，对个人创作者完全够用。

整套流程 5 分钟搞定，分四步：注册 Tavily → 复制 API Key → 粘到 InkPress → 验证一次。

## 准备工作

开始前确认你手上有这些东西：

- 一个 InkPress 软件，并且能进入「设置」页
- 一个邮箱，或 Google / GitHub 账号（用来注册 Tavily）
- 一台能装/已装 Authenticator 验证器的手机——Tavily 注册强制开启两步验证
- **不需要信用卡**

> 推荐 Authenticator：腾讯身份验证器（微信小程序）、Google Authenticator、Microsoft Authenticator，任选其一即可。

## 第 1 步：注册 Tavily 账号

打开 https://app.tavily.com ，点注册或登录。

- **登录方式三选一**：邮箱密码 / Google 账号 / GitHub 账号
- **预期结果**：注册成功后跳转到 Dashboard 控制台首页

⚠️ **关键提醒**：注册过程中会强制要求绑定 2FA（两步验证）。系统会让你扫一个二维码，用 Authenticator App 扫描后输入 6 位动态验证码才能继续。**这一步不能跳过**，所以提前装好验证器 App。

绑定成功后系统通常会给你一组**备份恢复码**——务必截图或抄下来存好，以后换手机、丢手机时全靠它救场。

## 第 2 步：复制 API Key

登录后默认就在 Dashboard 首页。页面上能直接看到 API Keys 区域，里面已经为你预生成好了一个默认 Key。

![Tavily 控制台首页，API Keys 区域就在这里](/guide-images/2026-07-05/acd81961-0af0-43b1-8e95-f9735aad08cf.png)

操作要点：

- **Key 的特征**：以 `tvly-` 开头，后面跟一串字母数字
- **示例格式**：`tvly-AbCdEfGh12345678`（这只是示例，别填这个）
- 点 Key 旁边的复制按钮，把 Key 复制到剪贴板

顺手在 Dashboard 看一眼剩余用量（Credits），新账户默认是 1,000。

## 第 3 步：在 InkPress 粘贴 Key

回到 InkPress，进入「设置」页，找到「联网搜索」面板。

![InkPress 设置页的联网搜索面板，Tavily Key 粘到这里](/guide-images/2026-07-05/0d1a96f2-4998-465c-a649-59ad0c7db1f6.png)

按顺序做：

1. 在「Tavily API Key」输入框粘贴刚才复制的 Key（占位符会显示成 `tvly-...`）
2. 点页面顶部或底部的「**保存配置**」按钮
3. **预期结果**：保存成功后，输入框会显示成 `********` 脱敏状态，说明系统已经加密存储了你的 Key

> 顺手理解一下旁边另外两个开关（可选，不影响联网搜索本身）：
>
> - **自动放权网页抓取（web_fetch）**：开启后 Agent 抓网页正文不再逐个问你授权；不开启则只对白名单域名免确认，其他域名每次都会问一下。建议先关闭，用一段时间后再决定。
> - **网页抓取域名白名单**：常抓的几个可信站点（如某个官方文档站）可以加进去，配合上面的开关用。

## 第 4 步：验证一次

最简单的验证方法：在 InkPress 里随便开一篇文章，让 Agent 查一个有时效性的问题，比如：

> 帮我搜一下 2026 年 7 月 OpenAI 最新的模型有哪些

如果配置成功，Agent 会调用联网搜索工具，返回带来源 URL 的搜索结果。

如果 Agent 回复「未配置联网搜索」或直接拒绝联网，说明 Key 没保存成功——回第 3 步重检查。

## 常见坑与排错

**Q1：Key 粘进去保存后显示** `********`**，是我填错了吗**？不是。`********` 是 InkPress 的脱敏显示，表示系统已经加密存储了你的 Key，用来防止页面被人偷看时泄漏。下次想改 Key，直接在框里输入新值覆盖；留空保存则保持原值不变。

**Q2：保存后 Agent 还是说没联网能力**？按顺序检查四件事：

1. Key 是不是真的以 `tvly-` 开头，前后没有多余空格
2. 复制时有没有截断（手机端偶尔会复制不全）
3. 浏览器有没有刷新设置页（有时候前端状态没更新）
4. Tavily 控制台里这个 Key 是否还有效（没被你自己撤销）

**Q3：注册时 2FA 扫码扫不出来**？换个光线好一点的环境，或检查 Authenticator App 是不是支持「扫码添加账户」。腾讯身份验证器小程序、Google Authenticator、Microsoft Authenticator 都行。绑定后**一定保存好备份恢复码**，换手机时要用。

**Q4：国内访问 Tavily 慢怎么办**？Tavily 服务器在海外，国内直连可用但速度不稳定。如果有代理/VPN，开起来注册和抓取都会顺畅很多。InkPress 这边的配置不用改，只是首次访问 Tavily 官网和注册那一下可能慢。

**Q5：Key 不小心泄漏了怎么办**？立刻按这个顺序处理：去 Tavily Dashboard 撤销泄漏的 Key → 生成一个新 Key → 在 InkPress 设置页粘贴新 Key 保存 → 确认旧 Key 已经删除。整个流程几十秒，越早处理越安全。

**Q6：免费额度用完了会怎样**？Agent 的联网功能会暂时失效（其他写作功能照常工作），等下个月额度刷新，或升级到付费档（最低 $30/月，约 4,000 credits）。
