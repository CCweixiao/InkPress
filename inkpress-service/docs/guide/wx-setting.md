## 为什么要先做这一步

用 InkPress 写完一篇公众号文章，最不爽的最后一公里就是：复制 → 切到公众号后台 → 粘贴 → 重新排版 → 保存草稿。

InkPress 内置了"一键发布到公众号草稿箱"的能力，可以跳过这一步。但它需要先做一次**一次性授权配置**——本质上就是让 InkPress 知道：你的公众号是谁、密码是什么、允许哪台服务器替你发文。

配置总共五步，做完就能长期用。下面一步一步来。

> 适用对象：公众号（订阅号 / 服务号均可）的**管理员**或**开发者**。如果你只是运营者，部分操作需要管理员扫码授权，下面会标注。

---

## 开始前你需要准备什么

- 一个已注册的微信公众号（个人订阅号也可以）
- 公众号管理员的微信（用于扫码登录和敏感操作授权）
- InkPress 账号，以及 InkPress 后台「公众号配置」入口

> 提醒：所有的 AppID、AppSecret 都属于敏感信息，相当于公众号 API 的"账号密码"。请只填在可信的工具里，不要截图发群、不要提交到公开代码仓库。

---

## 步骤 1：登录微信开发者平台

打开 **微信开发者平台**：<https://developers.weixin.qq.com/>

注意，是「**开发者平台**」，不是「微信开放平台」（open.weixin.qq.com）。这是两套不同的系统，公众号的开发配置目前在**开发者平台**这一边。

进入后用**管理员微信扫码**登录。

登录成功后，你会进入开发者平台主页，看到自己的头像和"我的业务"区域。

![微信开发者平台登录成功后的主页](/guide-images/2026-07-05/eda02212-c468-469b-ab3e-c36b35c5967b.png)

> 找不到入口？如果你之前习惯从 mp.weixin.qq.com 公众平台进"设置与开发 → 基本配置"找 AppSecret，那部分功能已经迁移到了 developers.weixin.qq.com 的「我的业务 → 公众号」。直接来这里就对。

---

## 步骤 2：进入「公众号」业务页

在主页的「我的业务」里，找到「**公众号**」并点击进入。

如果你名下既有小程序又有公众号，注意别点错——我们要的是公众号这一项。

![找到「公众号」业务入口并点击进入](/guide-images/2026-07-05/d67df844-9e40-4e37-a716-bb95b10f855d.png)

进入后，就能看到这个公众号的**基础信息**页面。我们要的三样东西都在这里：AppID、AppSecret、API IP 白名单。

![公众号基础信息页：在这里获取 AppID、AppSecret 并设置 IP 白名单](/guide-images/2026-07-05/991fb94c-1ee5-46b9-bfc7-3daa59ac8482.png)

---

## 步骤 3：拿到 AppID 和 AppSecret

在「基础信息」区域：

1. **AppID** 直接显示在页面上，复制下来即可。
2. **AppSecret** 默认是隐藏的。点击「**重置 / 显示**」按钮，**管理员扫码确认**后会重新生成一段密钥。
3. 把 AppSecret **立刻复制保存**到一个安全的地方。

> **非常重要**：AppSecret 只在重置那一刻显示**一次**，关闭页面就再也看不到了。如果忘了，只能再次重置——而一旦重置，**旧的 AppSecret 立即失效**，所有还在用旧密钥的地方（包括 InkPress）都要重新填一遍。所以建议在重置成功那一刻，**直接顺手复制到 InkPress 配置页**，避免中间遗失。

---

## 步骤 4：配置 API IP 白名单（最关键也最容易踩坑）

这一步是新手最容易卡住的地方，先讲清楚原理。

公众号的所有服务端 API（包括"新建草稿"接口）都要求：**调用方的服务器 IP 必须事先登记在白名单里**。InkPress 替你发文时，请求是从 InkPress 的服务器发出的，所以你要把 **InkPress 的服务器 IP** 加进白名单。

> 注意：这里填的是 InkPress 服务器的出口 IP，**不是你自己电脑的 IP**，也不是公众号后台显示的"你的客户端 IP"。具体 IP 值在 InkPress 的配置页面会明确告诉你，直接抄过去就行。

在「基础信息」页找到「**API IP 白名单**」一项，点编辑：

- **一行一个 IP**（回车换行分隔）
- 只支持 IPv4 地址，**不支持** `123.45.*.*` 这种通配符
- 不需要分号、逗号
- 填好后保存，**管理员扫码确认**

> 改完不要立刻测试，留 1~5 分钟让它生效。微信社区里大量"刚加完 IP 还是报错"的反馈，基本都是没等够时间。

---

## 步骤 5：回到 InkPress 填入并发布测试

打开 InkPress 的「**公众号配置**」页面，把你刚才拿到的两样东西填进去：

- **AppID** → 粘贴 AppID
- **AppSecret** → 粘贴 AppSecret

![在 InkPress 配置页填入 AppID 和 AppSecret](/guide-images/2026-07-05/5b6d64ed-d718-4c4a-90a8-5a1ddfb02905.png)

保存后，挑一篇**不太重要的旧文章**做一次"一键发布到草稿箱"测试，然后回到公众号后台的「内容管理 → 草稿箱」检查：

- ✅ 草稿箱里出现了这篇文章 → 配置成功，以后直接用
- ❌ 报错 → 看下面"常见问题"对应排查

---

## 常见问题与故障排查

### Q1：报错 `errcode: 40164 invalid ip xxx.xx.xx.xx, not in whitelist`

这是**最常见**的报错，意思是"调用接口的 IP 不在白名单里"。

排查顺序：

1. **看报错里显示的 IP**——这就是 InkPress 实际发出的出口 IP，把它原样复制下来
2. 回到微信开发者平台 → 公众号 → 基础信息 → API IP 白名单，把这个 IP 加进去
3. 等 1~5 分钟再重试

如果是云服务器（阿里云、腾讯云等）的出口 IP 因为负载均衡而变化，需要联系 InkPress 客服确认固定 IP。

### Q2：报错 `errcode: 40001 invalid credential`

access_token 失效或 AppSecret 不对。先检查：

- AppSecret 是不是漏掉了最后一位，或者复制时多了空格
- 是不是刚做过"重置 AppSecret"操作，但 InkPress 里填的还是旧的——把新 AppSecret 重新填一次

### Q3：报错 `errcode: 45009 api freq out of limit`

接口调用次数超过当日上限。InkPress 正常使用一般碰不到，如果你做了循环发布测试或者用了多个第三方工具同时调用同一公众号接口，可能会触发。等第二天自动恢复即可。

### Q4：配置完测试发布，草稿箱里没东西，也没报错

检查是不是登错了公众号。用 AppID 反查：AppID 在开发者平台和 InkPress 配置页应该完全一致。订阅号、服务号、个人订阅号容易混淆。

### Q5：操作过程中找不到"扫码确认"

扫码确认只对**管理员**可见。如果你是「开发者」或「运营者」角色，敏感操作（重置 AppSecret、修改 IP 白名单）会被拦截。让管理员登录后再操作，或让你升级为管理员。

---

## 最后再说两句

整套配置只做一次：拿到 AppID + AppSecret、加好 IP 白名单、填进 InkPress。之后写完文章，一键就能推到草稿箱，剩下的就是预览、群发。

如果哪天换了公众号、重置过 AppSecret、或者 InkPress 服务器换了 IP，回头改一下对应那一项就行——不用从头再做一遍。
