# 问题反馈

问题反馈用于处理产品使用、订单、账号和资料补充等问题。相比零散沟通，反馈记录能保留上下文、截图和处理状态，后续追踪更清楚。

## 什么时候提交反馈

- 购买或订单状态显示不符合预期。
- 账号登录、邮箱验证或密码修改遇到问题。
- 桌面端崩溃、发布失败或素材上传异常。
- 文章预览和实际发布效果不一致。
- 需要团队采购、发票或使用咨询。

## 提交反馈建议

1. 选择准确的问题类型。
2. 标题写清楚现象，例如 `发布预览中的代码块换行异常`。
3. 描述里写明操作步骤、错误提示和期望结果。
4. 上传截图或日志片段，避免只描述“不能用”。
5. 后续回复尽量在同一个反馈中补充，方便追踪。

## 状态说明

| 状态 | 含义 |
| --- | --- |
| 待处理 | 反馈已提交，等待查看 |
| 已回复 | 已给出回复或需要你补充信息 |
| 已解决 | 问题已处理完成 |
| 已关闭 | 反馈归档，不再继续处理 |

> 如果截图中包含邮箱、订单号或其他敏感信息，提交前可以适当遮挡，只保留定位问题必要的信息。
