# 工单支持

工单用于处理购买、激活、设备、发票和产品使用问题。相比邮件，工单能保留上下文和附件，管理员也能在后台统一处理。

## 什么时候提交工单

- 支付成功但控制台没有出现 License。
- License Key 无法激活。
- 设备数异常或需要人工协助换机。
- 需要企业采购、发票或批量授权。
- 遇到桌面端崩溃、发布失败或素材上传问题。

## 提交工单建议

1. 选择准确的问题类型。
2. 标题写清楚现象，例如 `macOS 激活提示设备数已满`。
3. 描述里写明操作步骤、错误提示和期望结果。
4. 上传截图或日志片段，避免只描述“不能用”。
5. 后续回复尽量在同一个工单中补充，方便追踪。

## 状态说明

| 状态 | 含义 |
| --- | --- |
| 待处理 | 工单已提交，等待管理员查看 |
| 已回复 | 管理员已给出回复或需要你补充信息 |
| 已解决 | 问题已处理完成 |
| 已关闭 | 工单归档，不再继续处理 |

> 如果问题涉及 License Key 明文，不建议直接发在公开截图里。可以说明 Key 后缀，管理员能在后台定位。
