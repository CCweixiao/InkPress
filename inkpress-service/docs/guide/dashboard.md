# 控制台与订单

控制台是普通用户的主要工作区，用来查看账号、邀请码、License、激活设备、订单和售后工单。

## 控制台包含什么

- **账户信息**：邮箱、昵称、角色、状态和注册时间。
- **我的邀请码**：用于 License 归因，管理员生成授权时可以绑定。
- **我的 License**：展示归属当前邮箱的 Key、有效期、设备数和激活记录。
- **归因 License 概况**：展示绑定你邀请码的授权概览。
- **我的订单**：查看支付状态、套餐、金额、创建时间和支付时间。
- **工单**：提交问题、补充材料并查看回复。

## 订单状态

| 状态 | 含义 | 建议动作 |
| --- | --- | --- |
| 待支付 | 订单已创建但未完成付款 | 回到支付页继续支付 |
| 已支付 | 付款成功，系统已生成或绑定授权 | 前往控制台查看 License |
| 已关闭 | 订单超时或被取消 | 重新选择计划下单 |
| 退款中 / 已退款 | 正在或已经完成退款 | 如有疑问提交工单 |

## 个人设置

个人设置页用于查看账号资料和修改密码。首次登录如果使用初始密码，系统会提醒尽快更换。

```text
建议密码策略：
- 至少 8 位
- 同时包含字母与数字
- 不要复用常用社交账号密码
```
