# 用户中心与订单

用户中心是登录后的个人入口，用来查看账号信息、订单记录、问题反馈和个人设置。它的目标是让用户快速找到和自己相关的信息，不需要在多个页面之间来回找。

## 用户中心包含什么

- **账户信息**：邮箱、昵称、角色、状态和注册时间。
- **我的订单**：查看套餐、金额、支付状态、创建时间和支付时间。
- **问题反馈**：提交使用问题、补充截图材料并查看回复。
- **个人设置**：维护基础资料和密码安全。
- **服务记录**：保留购买、咨询和问题处理的关键上下文。

## 订单状态

| 状态 | 含义 | 建议动作 |
| --- | --- | --- |
| 待支付 | 订单已创建但未完成付款 | 回到支付页继续支付 |
| 已支付 | 付款成功，服务权益已生效 | 前往用户中心查看订单详情 |
| 已关闭 | 订单超时或被取消 | 重新选择计划下单 |
| 退款中 / 已退款 | 正在或已经完成退款 | 如有疑问提交问题反馈 |

## 个人设置

个人设置页用于查看账号资料和修改密码。首次登录如果使用初始密码，系统会提醒尽快更换。

```text
建议密码策略：
- 至少 8 位
- 同时包含字母与数字
- 不要复用常用社交账号密码
```
