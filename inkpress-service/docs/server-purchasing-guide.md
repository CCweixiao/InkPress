---

## 0. 选型前提回顾

InkPress Service 的资源画像：

| 维度 | 估算 |
|------|------|
| 内存占用 | 200–400 MB（容器运行时） |
| CPU | 极低（License 验证是短连接） |
| 磁盘 | < 5 GB（系统） + 应用 + SQLite 数据库（MB 级） |
| 月流量 | 几 GB（每次激活/校验几 KB） |
| 公网带宽 | 不敏感，10 Mbps 都够 |
| 延迟 | **敏感**（影响用户体验，目标 < 80ms） |

结论：**1C1G 起步的小型 VPS 即可**，重点投入在**线路质量**而非配置。

## 7. 拿到服务器后的验收测试

### 7.1 基础连通性（必做）

```bash
# 本地 ping（多时段）
ping <服务器IP>

# 期望：
#   香港：30–60ms
#   美国 GIA：150–180ms
#   日本/韩国：50–80ms
```

### 7.2 多运营商测试（必做）

由于本项目面向国内用户，需确认三网都可达：

- 工具 1：https://ping.chinaz.com（站长之家多地点 ping）
- 工具 2：https://www.boce.com（拨测）
- 工具 3：https://itdog.cn（全面测试，含路由追踪）

判断标准：

| 指标 | 通过线 |
|------|--------|
| 电信延迟 | < 80ms（香港）/ < 180ms（美国 GIA） |
| 联通延迟 | < 80ms（香港）/ < 200ms（美国 GIA） |
| 移动延迟 | < 80ms（香港）/ < 200ms（美国 GIA） |
| 三网晚高峰（20:00–22:00）丢包率 | < 5% |

### 7.3 路由追踪

```bash
# 本地（macOS/Linux）
mtr -r -c 100 <服务器IP>

# Windows 用 WinMTR
```

关注回程路径是否经过 **CN2 GIA 节点**（节点名含 `cn2` / `gia` 关键词）。如果走 `163` 普通国际，晚高峰会丢包。

### 7.4 不达标处理

| 商家 | 退款政策 | 操作 |
|------|---------|------|
| DogYun 经典云 | 3 天内 + IP 未换 + 流量 < 5% | 工单申请退款 |
| DogYun 弹性云 | 随时销毁 | 后台直接销毁，余额退回 |
| 搬瓦工 | 30 天内 | 工单申请 |
| HostDare | 7 天内 | 工单申请 |
| 阿里云/腾讯云 | 按官方退款规则 | 控制台申请 |

## 8. 续费 / 升级 / 迁移

### 8.1 续费价格锁定

- **DogYun**：首次开通价（含优惠码 `2026` 折扣）**终身锁定**，续费不涨
- **搬瓦工**：首次开通价同样锁定，续费同价
- **阿里云/腾讯云**：按当前官网价续费，新用户优惠**仅首单**，第二年可能涨价

### 8.2 IP 被墙怎么办

| 商家 | 处理 |
|------|------|
| DogYun | 后台一键换 IP（部分机房收费约 ¥10） |
| 搬瓦工 | 切换机房功能可换 IP；CN2 GIA-E 套餐支持迁机房 |
| 阿里云/腾讯云 | 工单申请或销毁重建 |

### 8.3 跨商家迁移

本项目数据是 **SQLite 单文件**，迁移极简：

```bash
# 旧服务器
docker compose down
scp data/inkpress-service.db user@新服务器:~/inkpress-service-repo/inkpress-service/data/

# 新服务器
bash scripts/deploy.sh
```

详见 `deployment-production.md` §9。

## 10. 最终推荐

**给本项目（InkPress Service）的最优解**：

> **DogYun 香港-MG-BGP-s，月付，优惠码 `2026`，实付 ¥20/月**

理由：

1. **支付宝原生支付**，国内用户友好
2. **持 ISP 牌照**，比野生商家靠谱
3. **3 天退款**，试错成本接近零
4. **500GB 流量 + 1G 内存 + 100Mbps 带宽**，对 License 服务绰绰有余
5. **国内访问**：香港机房 + BGP 优化，三网延迟普遍 < 60ms
6. **续费不涨价**：首次价 ¥20/月终身锁定

**升级触发条件**（任一即考虑切方案 B 搬瓦工）：

- 电信晚高峰（20:00–22:00）连续多日丢包 > 10%
- 多地拨测延迟 > 150ms
- 工单响应超 24 小时未解决
