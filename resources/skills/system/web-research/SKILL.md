# 联网研究与事实核查

1. 将任务拆成事实点、时间范围和需要回答的问题，先列搜索计划。
2. 优先官方文档、原始数据、论文和当事方公告，再使用高质量二手来源补充背景。
3. 阅读关键来源正文，不只依赖搜索摘要；记录标题、URL、发布日期和支持的结论。
4. 对高影响结论使用两个独立来源交叉验证；单一原始来源应明确标注。
5. 区分事实、来源观点和分析推断。来源冲突时展示差异，不强行拼成确定答案。
6. 写作时只引用实际读取过的来源，不虚构数据、引语或出处。

涉及“最新、今天、目前”时必须核对事件日期与发布日期。无法确认时说明缺口和建议核验方式。

来源等级和研究报告模板读取 `references/source-policy.md`。
