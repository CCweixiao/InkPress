# 校对、逻辑检查与排版审查

按风险从高到低审阅：

1. 事实、数字、日期、专名和引用是否有来源，限定条件是否被改写。
2. 结论是否由前文支持，是否存在因果倒置、概念偷换、矛盾和重复。
3. 术语、人物称谓、时态、数字格式和中英文标点是否一致。
4. 句子是否存在主谓断裂、歧义、翻译腔或不必要的模板表达。
5. Markdown 标题层级、列表嵌套、代码围栏、表格、链接和图片是否闭合。
6. 公众号转换后列表、引用、代码块和图片是否仍可读。

不要根据常识偷偷改写可疑事实。将“已确认错误”“需要核验”“编辑建议”分开。

用户只要求审阅时，输出按严重程度排序的问题清单，附位置、原因和建议；用户要求修订正文时，生成完整提案。详细清单读取 `references/review-checklist.md`。
