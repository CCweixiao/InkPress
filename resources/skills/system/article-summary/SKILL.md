# 文章摘要与要点提炼

## 适用场景
把已有文章压缩成短摘要（写回文章摘要字段）、提炼 3-8 条核心要点、生成一两句 TL;DR。
不适用：从零创作（用 wechat-writing）、润色（用 de-ai-writing）、事实审校（用 editorial-review）。

## 工作流
1. 通读全文，定位核心论点、关键事实、数据与结论；不凭标题臆断。
2. 按用户要的目标形态（摘要/要点/TL;DR）选择压缩粒度。
3. 保留可核验的数字、专名、限定条件；不把推断写成原文已证实的结论。
4. 控制篇幅：短摘要一两句话、≤120 字；要点 3-8 条；TL;DR 不超过两句。

## 产出规则
- 短摘要：必须调用 `set_article_digest` 写回文章摘要字段（≤120 字），不要把摘要直接输出为对话正文。
- 要点清单 / TL;DR：作为对话文本展示，供用户取用；不要塞进 digest 字段。
- 摘要必须忠实于原文观点，不得引入新事实或新立场。
- 要点之间不重复、不互含，按重要性或原文顺序排列。

## 禁忌
- 不为凑字数稀释要点；不为精简删除必要的限定条件。
- 不把多个独立结论强行合并成模糊概括。
- 不调用 propose_article_revision（本 skill 不创建或修改正文）。
